# Task-02: Image Generation with Pre-trained Models

## Objective

Generate an image from a text prompt using a pre-trained Stable Diffusion model.

## Model Used

- Stable Diffusion
- KerasCV
- TensorFlow

## Description

For this task, Stable Diffusion was used to generate an image from a text prompt. The model converts the text description into a generated image using the diffusion process.

## Prompt

"Realistic cinematic photograph of an astronaut riding a white horse, full horse visible, horse facing slightly toward the camera with a clear visible eye and detailed face, natural four-leg anatomy, astronaut fully visible, futuristic desert landscape at sunset, warm side lighting on the horse, balanced exposure, sharp focus, realistic textures, professional photography."

## Parameters

- Batch size: 1
- Diffusion steps: 25
- Image size: 512 × 512

## Output

The generated image is included in this folder as:

`task02_astronaut_horse.png`

## Technologies

- Python
- TensorFlow
- KerasCV
- Stable Diffusion
