# Task 05 - Neural Style Transfer

## Objective
Apply the artistic style of one image to the content of another image using Neural Style Transfer.

## Description
In this task, I implemented Neural Style Transfer using Python and TensorFlow.

A content image and a style image are provided as inputs. The model combines the content of the first image with the artistic style of the second image to generate a new stylized image.

## Technologies Used
- Python
- TensorFlow
- NumPy
- Matplotlib
- Google Colab

## Input
- Content Image
- Style Image

## Output
The final output is an image that preserves the main content of the content image while applying the artistic style of the selected style image.
